## 맵 확장 (2026-10-14 시험, 2026-10-15 적용: 동쪽 +48 → 184x136)

- 사용자 지시: 맵을 키우고 동맹 1은 중앙 동굴 통로처럼 생긴 곳, 동맹 2는 동쪽.
- 중앙 통로 = 발굴지 절벽 장식(`TRaynor02DigSite`, 48,78)으로 해석. 이 자리는 원본 `Dominion Base` 지역의 원 하나(46.9,77.6 반지름 8.4) 안이고 자치령 기지(45,94)와 가깝다.
- 원본 플레이 지역(카메라 16~120 x 8~120)은 동쪽 끝이 높은 고원으로 막혀 있어서, x=104 경계 동쪽을 서쪽 지형의 **거울 복사**로 바꿨다. 크기 136x136 → 200x136, 카메라 오른쪽 경계 120 → 184.
- 원래 좌표가 그대로라 유닛·지점·지역·스크립트를 고칠 필요가 없다. 경계 동쪽에 있던 장식물·차단 지점 104개는 지웠고(스크립트 참조 없음 확인), 서쪽 장식물 893개를 대칭 복사했다.
- 새 지역의 경사로 1곳은 평평하게 메웠다 (경사로 기하 정보를 대칭 복사하지 않음). 버텍스 색(`t3vertcol`)과 `t3hardtile`은 형식을 몰라 그대로 둠.
- 편집기용 맵: `python3 tools/make_edit_map02.py` → `build/TRaynor02_edit.SC2Map`, 단일 파일은 `tools/pack_sc2map.py`. 동맹 시작 표시 지점 `rm Ally1 Purifier Start`, `rm Ally2 Primal Start`.
- 검증: 파일 크기·XML·서쪽 원본 일치·대칭 일치·MPQ 왕복 확인. **편집기·게임에서 열어 보는 검증은 미실행.**

### 동쪽 새 지형 (2026-10-15, 0.2.2)

- 거울 복사(0.2.1)는 사용자 지시로 버리고 `tools/new_terrain.py`로 새로 그림. 배치도는 `tools/patch_mission02.py`의 `east_layout`.
- 1단계 들판(x 104~약 166, y 약 16~112)을 3단계 고원이 둘러싸고, 들판 안에 고원 바위 3개 (`EAST_ISLANDS`). 경사로 없음.
- 새 칸·꼭짓점 값은 원본의 단계별 대표값 (꼭짓점 단계 = 맞닿은 칸 최댓값, 절벽 칸 표시 3, 평지 2, 텍스처는 단계별 가장 흔한 것).
- 검사: 파일 크기·XML, 레이너 본진에서 새 들판 1단계 칸 5717개 중 5715개 도달(절벽·경사로 규칙 기준). 경계 x=104는 원본 지형과 직선으로 맞닿음.
- 편집기·게임 확인은 미실행. 텍스처가 한 종류라 밋밋할 수 있음 → 편집기에서 칠하거나 다음 단계에서 보강.
