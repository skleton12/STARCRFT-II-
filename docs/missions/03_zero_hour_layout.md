# 3번 임무 — 0시를 향하여 배치 계획

2026-10-16 사용자 첨부 이미지 기준. 요구 사항을 기록한 계획이며 맵에 적용된 상태는 아니다.

## 사용자 지정 배치

- 남서쪽에 멀티 기지 2곳을 마련하고 자원을 추가한다.
- 이미지의 노란 X 두 곳은 지원군 투하 위치이자 기지 건설 위치다.
- 왼쪽 X는 이미지상 대략 (171, 727), 오른쪽 X는 (269, 724)에 있다. 이는 첨부 이미지의 픽셀상 참고 위치이며 게임 좌표가 아니다.
- 동맹 진영 표시 이름은 확정 규칙인 `정화자`, `원시저그`를 사용한다.

## 실제 배치 시 확인할 사항

원본 3번 맵을 확보해 이미지와 지형을 대조한 뒤 게임 좌표를 정한다. 두 기지의 건설 공간, 투하 공간, 자원 채취 동선과 출입로를 확보한다. 이미지상 남서쪽에는 기존 적 병력·건물이 있으므로 겹치는 배치와 기존 공세·목표 트리거를 확인한다.

두 X 중 어느 쪽이 정화자/원시저그 기지인지는 아직 지정되지 않았다. 자원 덩이 수·매장량·기지 간격·등장 시점·기지 건물 구성 역시 미확정이다. 기존 2번 맵 자원 수치를 3번 맵 확정값으로 간주하지 않는다.

## 2026-10-16: 3번 맵 동맹의 적 기지 정화 후 지원 — 사용자 확정
