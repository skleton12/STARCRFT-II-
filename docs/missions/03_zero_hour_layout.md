# 3번 임무 — 0시를 향하여 배치 계획

2026-10-16 사용자 첨부 이미지 기준. 요구 사항을 기록한 계획이며 맵에 적용된 상태는 아니다.

## 사용자 지정 배치

- 남서쪽에 멀티 기지 2곳을 마련하고 자원을 추가한다.
- 이미지의 노란 X 두 곳은 지원군 투하 위치이자 기지 건설 위치다.
- 왼쪽 X는 이미지상 대략 (171, 727), 오른쪽 X는 (269, 724)에 있다. 이는 첨부 이미지의 픽셀상 참고 위치이며 게임 좌표가 아니다.
- 동맹 진영 표시 이름은 확정 규칙인 `정화자`, `원시저그`를 사용한다.

## 실제 배치 시 확인할 사항

원본 3번 맵을 확보해 이미지와 지형을 대조한 뒤 게임 좌표를 정한다. 두 기지의 건설 공간, 투하 공간, 자원 채취 동선과 출입로를 확보한다. 이미지상 남서쪽에는 기존 적 병력·건물이 있으므로 겹치는 배치와 기존 공세·목표 트리거를 확인한다.

두 X 중 어느 쪽이 정화자/원시저그 기지인지는 아직 지정되지 않았다. 자원 덩이 수·매장량·기지 간격·등장 시점·기지 건물 구성 역시 미확정이다. 기존 2번 맵 자원 수치를 3번 맵 확정값으로 간주하지 않는다.

## 2026-10-16: 3번 맵 동맹의 적 기지 정화 후 지원 — 사용자 확정

사용자가 남서쪽 표시 지점의 적 기지를 동맹이 먼저 정리한 뒤 지원하는 흐름에 동의했다. 정화자 쪽은 태양 광선으로 진입 지역을 공격한 뒤 병력이 소환되는 연출을 사용한다. 전체 진행은 동맹의 적 기지 정리 → 표시 지점 기지 확보·건설 → 레이너 지원이다. 원시저그의 구체적인 진입 연출, 좌우 진영 배정, 광선 범위·피해량·시간과 기지 구성은 미확정이다. 광선으로 반드시 모든 적이 즉사하거나 기존 임무 목표가 자동 달성된다고 가정하지 않는다. 최초 확보 연출과 후속 지원을 구분하며 정확한 구현 조건은 원본 맵 확인 후 정한다. 이번에는 기획을 기록했으며 맵·배포 ZIP은 변경하지 않았다.

## 2026-10-17: 정화자 병력 출처 제한 — 사용자 확정

사용자는 정화자 동맹의 병력을 협동전 정화자 유닛 중 피닉스·카락스 소속으로 제한하고 피닉스 중심으로 구성하도록 지시했다. 피닉스 병력을 주력으로, 카락스 병력을 보조로 삼는다. 캠페인 전용 정화자 또는 다른 사령관 유닛을 정화자 동맹에 임의로 포함하지 않는다. 이는 향후 병력 구성 및 기존 이식본 검토 기준이며 이번에는 특정 유닛 수·새 영웅을 추가 확정하거나 배포 ZIP을 변경하지 않았다. 현재 파수병·선동자·동력기 구성은 재검토 대상이다. 선동자(StalkerPurifier)를 피닉스 협동전 유닛으로 간주하면 안 된다. 피닉스의 협동전 병력은 군단병·사도 등을 기준으로 실제 사령관 생산 데이터를 확인한다. 현재 ZealotPurifier에도 피닉스 변환과 카락스 재구축 연결이 섞여 있어 ID·외형만으로 순수 사령관 구성을 단정하지 않는다. 피닉스 중심 구성으로 바꾸는 것은 후속 맵 수정에 적용해야 한다. 유닛 ID만 같아도 사령관별 효과가 다를 수 있어 실제 능력·무기·연구 정의까지 확인한다.
