# 다음 작업: 대지파괴 포 연구·프로메테우스 중대

기록: 2026-10-30 한국 시간. 사용자는 내일(10월 31일) 적용해 볼 계획으로 기록을 요청했다. 이번에는 문서만 작성하며 자동 예약·맵 수정·배포는 하지 않는다.

## 대지파괴 포 — 적용할 연구안

| 항목 | 기록한 내용 | 상태 |
|---|---|---|
| 기본 사거리 | 20 | 사용자 지정 |
| 반구형 가속제 연구 후 포탄 수 | **포격 1회당 8발** | 사용자 지정 |
| 연구 후 공격 속도 | +50% | 사용자 제시 연구안 |
| 연구 후 사거리 | 기본보다 +5~10 | 사용자 제시 범위. 최종 증가량 미정 |
| 연구 후 공격력 | 증가 | 증가율 미정. +20%는 Codex 제안이며 사용자 확정 아님 |
| 기본 포탄 수 | 마지막 확인한 구현은 4발 | 적용 전 최신 파일 재확인 |
| 연구 비용·시간·선행 조건 | 미정 | 임의로 확정하지 않음 |
| 최소 사거리·포탄 간 발사 간격 | 미정 | 공성포 느낌을 검토했지만 확정하지 않음 |

사용자는 고정식 공성 전차 같은 운용감을 고려했다. 자치령 인부가 현재 모드에 없어 인부 탑승 체계를 가져오지 못하는 상황이다. 인부 불필요를 별도 업그레이드/보상으로 만들지 않는다. 오염된 강타는 마지막으로 확인한 구현에서 제외돼 있으며 이번에 추가 지시하지 않았다.

공격 속도 +50%는 주기를 절반으로 하는 것이 아니라 **기존 주기 ÷ 1.5**다. 기본 4발→8발과 동시에 적용하면 포탄당 피해가 같아도 명목 화력은 3배다. 포탄당 피해까지 +20%로 선택하면 3.6배이지만, +20%는 미확정이다. 실제 명중·방어력·범위 중복은 게임 시험에서 구분한다.

## 프로메테우스 중대 — 후속 작업

- 참고 원본: 사용자 드라이브의 Wings of Mengsk (Zishen) - Translated → WoM-1.3_Armory.zip → WoMRoyalGuards.SC2Mod.
- 확인한 유닛: **Prometheus Company / FirebatMengsk**. 한국어 ‘프로메테우스 중대’는 설명용 번역이며 공식 번역 확인 아님.
- 원본 생산은 BarracksMengsk → BarracksMengskTrain,Train4 → FirebatMengsk. 고용소 생산 사례라고 단정하지 않는다.
- 원문 진급 툴팁: 1등급 Jump Jet Assault, 2등급 Juggernaut Plating, 3등급 Advanced Stimpack.
- 사용자 요청 외형 방향: 용병/근위대 같은 느낌, **검붉은 색조**. 기존 모델·액터·텍스처를 확인한 뒤 구현 가능한 방식을 정한다. 특정 모델은 아직 확정하지 않았다.
- 현재 프로젝트에서는 고용소의 멩스크 계열 화염 용병 후보로 검토한다. 고용 수·비용·대기시간·업그레이드 대상·초기 등급의 세부 구현은 최신 클로드 명세에 맞춘다. Codex가 제안한 ‘처음부터 3등급’만으로 확정하지 않는다.
- 병영 악마의 개와 고용소 화염 용병의 역할을 구분하며, 원본 모드 전체·사령관 체계를 통째로 이식하지 않는다.
- 상세 원본 확인은 로컬 /workspace/reference-mods/wom/PROMETHEUS_FINDING.ko.md 및 추출 데이터에 남아 있다. 작업 환경이 바뀌면 파일 실재부터 확인한다.

## Claude → Codex 작업 인수인계 시험

사용자는 프로메테우스 중대 작업을 Claude가 명세하고 Codex가 수행하는 흐름을 시험할 계획이다. 자동 메시지 연동이나 자동 실행이 이미 설정됐다고 가정하지 않는다.

### 추가 기록 — Chrome을 통한 지시 전달 (2026-10-31 한국 시간)

사용자는 Google Chrome을 이용하면 Claude에게 명령을 전달할 수 있는 것 같다고 말했다. 브라우저 자동화 도구와 해당 Claude 세션 접근이 제공되는 환경에서는 이 방식을 검토할 수 있다. 현재 이 대화에서는 브라우저 제어 도구나 Claude 세션 연결을 확인하지 못했으며, 실제 지시 전달·자동 연동을 시험하거나 설정한 상태는 아니다. 따라서 불가능하다고 단정하지 않되, 연결이 완료됐다고도 기록하지 않는다. 브라우저로 전달하더라도 실제 작업 명세와 결과는 저장소 문서·변경 내역으로 남긴다.

Claude가 동일 저장소에 아래를 담은 인수인계 문서를 남기고, 사용자가 Codex에 그 문서를 기준으로 작업하도록 요청하는 방식으로 진행한다.

1. 대상 브랜치·기준 커밋/ZIP 버전·적용 미션.
2. 고용소 버튼/능력 슬롯, 유닛 ID, 고용 수·가격·재사용 대기.
3. 모델/색조, 초기 등급, 연구·공방업 적용 대상, 제외할 사령관 기능.
4. 허용 변경 범위와 완료 검사.

실제 작업 전 최신 CLAUDE.md와 docs/HOW_TO_BUILD_AND_PATCH.md를 다시 읽고, 현재 작업 브랜치 claude/determined-euler-pksrrt의 최신 ZIP 위에서 진행한다. 과거 브랜치 claude/lucid-franklin-ed0eko를 최신으로 착각하지 않는다. 다른 AI가 먼저 수정했으면 그 내용을 보존한다. 필수 검사 통과와 실제 게임 시험을 구분하며, 사용자가 금지한 별도 시험본을 임의로 만들거나 배포하지 않는다.
