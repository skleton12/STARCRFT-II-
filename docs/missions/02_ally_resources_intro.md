# 2번 미션 추가 요구: 동맹 자원·상태 표시·도착 안내

기록일: 2026-10-15. 사용자 지시를 정리한 기획 인수인계이며 **구현 완료 보고가 아니다**.

## 사용자 요구

1. 정화자와 원시 저그 진영에도 자원을 배치한다.
2. 각 동맹이 얼마나 자원을 보유하고 있는지 플레이어에게 표시한다.
3. 미션 시작 시 부관이 저그·프로토스 지원군 도착을 알린다. 부관 얼굴(초상화)을 함께 표시한다.

적용 범위는 현재 작업 중인 2번 미션이다. 다른 임무로 일괄 확정하지 않는다.
사용자의 지도 낙서는 임시 구상이며, 검은 표시는 기존 지도 검은 영역과 같은 지형을 뜻한다. 공격 경로 표시로 해석하지 않는다.

## 구현 검토 기준

### 동맹 자원 배치

- 두 진영 모두 자원 배치를 계획한다. 광물·가스를 기준으로 검토하되 덩이 수·총 매장량·배치 반경은 미정이다.
- 자원은 기지 평지에 두고 소환점·출구·병력 집결 공간과 겹치지 않도록 한다.
- 자원을 놓는 것과 AI가 실제 채취하는 것은 별도 작업이다. 종족별 일꾼, 반환 건물, 가스 채취 건물, 채취 명령이 필요한지 확인한다.
- 원시 저그의 채취 유닛·기지 구성을 임의로 데하카/일반 저그 운영 방식으로 확정하지 않는다.
- 현행 무료 시간제 소환(90초, 첫 소환 포함 6회)은 이 요구만으로 자원 지출형 생산으로 바꾸지 않는다. 경제와 기존 소환의 관계는 미정이다.

### 자원 상태 표시

- 정화자·원시 저그를 구분해 이름과 자원량을 표시한다.
- 기본 제안: 각 플레이어(8·9)의 실제 보유 광물·가스. 지도의 남은 매장량과 보유 자원을 혼동하지 않는다.
- 예시 형식(값은 자리표시자): 정화자 | 광물 {보유량} | 가스 {보유량}; 원시 저그 | 광물 {보유량} | 가스 {보유량}.
- 위치·모양·갱신 주기는 미정이다. 0과 자원 부족도 그대로 표시하며 실제 경제와 무관한 가짜 수치를 넣지 않는다.
- 시작 자원·채취 수입·생산 지출·증원 비용을 어느 시스템이 관리하는지 정한 뒤 표시와 실제 잔고를 일치시킨다.

### 시작 부관 안내

- 기본 시작 연출과 충돌하지 않는 미션 시작 구간에 부관 전송을 넣는다.
- 부관 초상화와 도착 안내 문장을 함께 보여준다.
- 한국어 대사 초안: “사령관님, 저그와 프로토스 지원군이 도착했습니다.”
- 영어 초안: “Commander, Zerg and Protoss reinforcements have arrived.”
- 위 문장의 정확한 표현은 GPT 초안이다. 사용자 확정은 도착 안내의 내용·화자·얼굴 표시다.
- 실제 지원군 첫 생성과 안내 시점을 맞춘다. 아직 생성되지 않았는데 도착했다고 알리지 않는다.
- 사용할 음성 리소스는 확인 필요. 정확한 대사의 기존 음성이 존재한다고 가정하거나 다른 문장의 음성을 해당 대사라고 표기하지 않는다. 초상화·자막·음성 적용 상태를 각각 보고한다.
- 연출 건너뛰기·저장/불러오기에서 안내와 지원군 생성이 중복되지 않게 한다. 자막은 기존 한국어·영어 문자열 규칙을 따른다.

## 미정 항목

자원 수량·매장량, 시작 잔고, 채취 일꾼·기지 구성, 생산/증원 비용, 자원 부족 시 AI 행동,
상태 표시 위치·갱신 주기, 실제 안내 음성. 이번 지시로 새 화폐·동맹 자원 송금·무한 자원·자동 재생성은 확정되지 않았다.

## 재시험

| 조건 | 기대 결과 |
|---|---|
| 양쪽 진영 첫 확인 | 자원과 소환 병력·출구가 겹치지 않음 |
| 채취를 구현한 경우 | 일꾼이 실제로 채취·반환하고 해당 동맹 잔고 증가 |
| 동맹별 잔고 변화 | 표시값이 올바른 플레이어 잔고와 일치 |
| 생산/증원 비용을 도입한 경우 | 정해진 시점에 정확히 한 번 지출, 부족 처리 일관 |
| 미션 시작 및 연출 건너뛰기 | 부관 얼굴·도착 안내·실제 병력 도착이 맞음 |
| 저장/불러오기 | 표시·잔고 유지, 첫 지원군·안내 중복 없음 |

현재 상태: **요구 기록 완료 / 맵·스크립트·음성 구현 및 게임 시험 미실행**.
