# 1번 미션: 해방의 날 (Liberation Day)

상태: 착수 전. 원본 맵을 아직 받지 못했다.

## 원본 (맵으로 확인 필요)

아래는 기억에 기댄 요약이다. 원본 맵 파일과 트리거로 확인하기 전에는 정확한 값으로 쓰지 않는다.

- 장소: 마 사라, 마 사라 시
- 플레이어: 레이너(영웅) + 해병 소수. 기지 건설 없음
- 목표: 마을 안의 자치령 병력 처치
- 적: 자치령 해병 등 소규모 보병

## 이 모드에서 바뀌는 점

확정 방향(CLAUDE.md 3장) 중 1번 미션에 닿는 것:

| 항목 | 상태 | 내용 |
|---|---|---|
| 레이너 유닛은 모두 용병 | **확정** (2026-10-13) | 레이너가 데리고 다니는 해병도 용병이어야 한다 |
| 용병은 멩스크 유닛 기반 | 확정 방향 | 해병 역할을 어느 멩스크 유닛에 연결할지는 **미정** |
| 해병 역할 연구 | 후보 | 1번 미션은 연구 건물이 없으므로 연구 적용은 이후 미션부터 |
| 동맹(정화자·원시 저그) | 확정 방향 | 등장 미션 **미정**. 1번에 넣을지 결정 필요 |
