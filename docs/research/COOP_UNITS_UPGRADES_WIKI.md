# 협동전 유닛·업그레이드 조사 위키

조사일: 2026-10-17 (한국 시간) / 상태: 자료 조사·참고용 / 대상: 협동전 18명 사령관.

**이 문서는 모드 적용 사양서가 아니다.** 3번 미션부터 연구 구성을 설계할 때 사용할 자료다. 이번 작업에서 맵·CCM ZIP·연구 효과를 변경하지 않았다. 기존 테란 중심 설계 범위는 유지하며, 다른 종족과 감염된 테란은 비교 자료로 수록했다.

## 읽는 법

- `연구`: 미션 안에서 자원과 시간을 지불하는 유닛·건물 특수 업그레이드.
- `장비 / 궁극 장비`: 타이커스 무법자별 구매. 일반 연구·레벨 특성과 별개.
- `유물`: 제라툴의 조각 획득으로 자동 해금되는 능력.
- `진급 / 진화`: 경험치·정수·희생·원시 전투 등 전투 중 성장.
- `특성 / 마스터 힘 / 위신 / 패널`: 일반 연구와 따로 보며, 각 사령관 원문 링크로 연결한다.

표의 비용은 **광물/가스**, 시간은 **출처가 표기한 초**다. 마스터 힘·위신·사령관 레벨로 달라질 수 있으므로 구현에 그대로 복사하지 않는다. 타이커스 장비 비용처럼 표에서 직접 확인되지 않은 값은 임의로 채우지 않았다. 제라툴의 `유물 n`은 비용이 아니다. 짧은 효과 설명은 검색·분류용 요약이며 세부 수치·예외는 연결된 원문을 확인한다.

영문 항목명은 동명 기술과 번역 차이를 구별하기 위한 검색 키다. **Galaxy/XML 카탈로그 ID가 아니다.** 일꾼·알·요격기 등 모든 보조 개체의 도감이나 공격력/방어력 전체 수치표를 의미하지 않는다. 전투 유닛·영웅·패널 병력과 공개 가이드의 특수 강화표를 중심으로 정리했다.

## 공통 공방업과 해금

| 구분 | 확인할 연구 계열 | 주의점 |
|---|---|---|
| 테란 | 보병 무기·장갑, 차량·우주선 무기·장갑 | 사령관별 통합 여부와 대상이 다름 |
| 저그 | 근접·원거리 공격, 지상 갑피, 비행체 공격·갑피 | 원시·메카·감염 병력의 실제 적용 계열 확인 |
| 프로토스 | 지상·공중 무기·장갑, 보호막 | 보호막과 선체 장갑을 구분 |
| 타이커스 | 무법자 무기, 생명력·방어력 | 4·5단계는 사령관 레벨 해금 필요 |
| 제라툴 | 유물 기반 무기·장갑·보호막 성장 | 일반 연구 건물에서 사는 체계가 아님 |

일반 공방업의 세부 비용과 선행 건물은 공통값으로 단정하지 않는다. 차원 관문·잠복·건물 변이 등 생산 체계 연구도 유닛 전용 강화와 구분한다. 별도 전용 연구가 없는 유닛도 공방업·특성의 영향을 받을 수 있다.

## 피닉스와 현재 모드의 정화자 병력

피닉스 군단병·사도와 카락스 파수병·동력기, 다른 캠페인/모드의 정화자 유닛은 같은 표시명·외형이라도 기술이 다를 수 있다. 현재 모드의 `ZealotPurifier`·`StalkerPurifier`에 어느 연구가 연결되는지는 별도 데이터 검사가 필요하다. 이 문서를 읽었다고 정화자 지원군에 카락스 재구축이나 피닉스 용사 시스템을 자동 부여하지 않는다.

## 출처와 검증 범위

- 각 사령관의 전투 개체·전용 연구 표를 직접 확인하고, 동일한 연구가 여러 유닛에 반복된 경우 한 행으로 묶었다. 같은 이름이어도 대상·가격이 다른 추적자/암흑기사 점멸은 두 행으로 유지했다.
- Starcraft2Coop는 커뮤니티 가이드다. 공식 사령관 소개와 성장 체계 설명을 교차 확인했다. 공식 소개는 출시 당시 자료이므로 현재 모든 수치를 보증하는 근거로 사용하지 않았다.
- 효과 문구는 한국어 검색용으로 요약했다. 이 문서는 게임 클라이언트 카탈로그 전수 덤프·Galaxy 컴파일·실제 실행 검증 결과가 아니다.
- 건물별 모든 생산 기술·개별 유닛 공격력/체력/스킬 툴팁·마스터 힘별 모든 수치·54개 위신의 장단점 전문은 연결된 원문 영역에서 확인한다. 누락을 감추기 위해 ‘모든 게임 데이터 검증 완료’라고 표기하지 않는다.
- 수치 충돌 사례: 레이너 공성 기술은 같은 가이드 안에서도 소개부와 상세표의 방어력 서술이 달라 효과 요약에서는 정확한 증가량을 확정하지 않았다. 공식 게임 데이터 대조가 필요하다.
- 나무위키·Liquipedia 등에서도 사령관별 자료를 찾을 수 있으나, 이 문서의 직접적인 행별 근거는 각 절에 연결한 가이드와 명시된 보충 자료다.
