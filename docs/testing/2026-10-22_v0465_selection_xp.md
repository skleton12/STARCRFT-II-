# 0.4.65 — 동맹 혼합 선택과 근위대 경험치

사용자 요청: 동맹 병력이 내 병력과 함께 드래그돼 방해되는 문제 수정. 앞선 대화의 주변 처치 경험치 분배 복구를 함께 반영한다.

어부지리에서 플레이어 1의 병력 또는 건설용 동맹 일꾼(8번 Probe, 9번 DehakaDrone)이 선택되어 있으면 함께 선택된 8·9번의 다른 유닛과 건물을 선택에서 제외한다. 동맹만 선택한 경우에는 그대로 두어 단독 클릭으로 확인할 수 있다. 데이터의 선택 불가 플래그를 쓰지 않는다. 선택 이벤트가 발생한 뒤 정리하므로 게임에서 순간적인 선택 표시 여부는 확인이 필요하다. Shift로 혼합 선택해도 같은 규칙이 적용된다.

코랄의 후예와 이지스 근위대는 레이너·두 동맹이 적을 처치하면 경험치를 분배받는다. SC2Mapster/SC2GameData 6dd323aae4209a01f110719a00b4e8f7a88389bc의 LibCOMI.galaxy, CM_Mengsk_VeterancyEarned 기준: 사망 위치 반경 15 안의 미완성 진급 근위대 우선, 없으면 지도 전체의 해당 근위대로 분배한다. 적 보급당 100, 보급 0 영웅은 800, 인원수로 나누어 반올림하며 최소 1. 건물·중립·환영·명령 불가 소환체 등은 제외한다. 이 모드의 두 근위대와 아군 슬롯에 맞춘 구현이며 마스터 힘·위신·돌연변이 체계는 이식하지 않는다. 직접 처치 경험치를 0으로 바꿔 중복 지급을 막고, 기존 진급 요구량과 능력치는 보존한다.

검증: 전체 check_release 통과, 선택 정책 5사례(동맹 단독/혼합/선택 순서 반전/동맹 일꾼/수정탑), 이벤트 등록 단일성, 직접 처치 경험치 차단, 사용 네이티브 API 실재 확인. 0.4.64 대비 ZIP은 metadata·4번 mapscript·4번 behaviordata만 변경. 1~3번 및 모든 지형·배치는 보존. 실제 게임·Galaxy 컴파일·선택 이벤트 타이밍·경험치 실지급은 미실행.

재현: `python3 tools/build_v0465.py <0.4.64 ZIP> <새 출력 ZIP>`
