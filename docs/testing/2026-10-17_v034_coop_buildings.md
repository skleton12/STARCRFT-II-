## 0.3.3에서 문서와 어긋났던 것과 수정

| 항목 | 0.3.3 | 0.3.4 |
|---|---|---|
| 원시저그 본진 | 일반 `Hatchery` 외형만 원시 모델 | 데하카 실제 유닛 `DehakaHatchery` (원시 군락) |
| 원시저그 생산 건물 | 일반 `SpawningPool` 외형 변경 | `DehakaBarracks` (원시 감시자) |
| 원시저그 일꾼 | 일반 `Drone` 외형 변경 | `DehakaDrone` (원시 일벌레) |
| 추출장 | `Extractor` + 원시 추출장 외형 | 유지 (기준표: 공유 ID가 맞음) |
| 정화자 병력 | 선동자 `StalkerPurifier` 2 (협동전 유닛 아님) | 피닉스 사도 `AdeptFenix` 2 |
| 정화자 건물·탐사정 | 공통 ID + 피닉스 정화자 외형 | 유지 |

- 이식: `port_units.py --liberty-base --skip-existing --drop=...`. 기준표의 "자동 추가 금지"에 따라 알 생산(`*TrainEgg`), 뿌리 들기, 일벌레 건설(`DehakaDroneMorph`), 군락 건설·연구, 글레빅·멀바르·다크룬 굴, 원시 벌레, 탈리스 용사 변신은 이식하지 않았다.
- 원시 일벌레는 일반 저그 AI가 만들 수 없어 스크립트가 12기 유지(2초마다 1기 무료 보충, **시험값**)하고 쉬는 일벌레를 가까운 광물로 보낸다. 일반 저그 AI 생산 목록(드론·부화장·산란못·대군주)은 지웠다.
- 파수병 8·동력기 1(카락스 소속, 사용자 선택)은 유지. 기준표의 "피닉스 중심" 재편 범위(파수병→군단병 등)는 사용자 결정 대기.
- 이식으로 생긴 끊긴 하위 연결 96개는 자동 삭제. 3번 맵 빈 연결 후보 322 → 320 (새로 생긴 것 0).
- 배포 전 한국어 검사: 세 맵 kokr 표시 문자열에 영어만 있는 값 0개 (검사 실패 시 빌드 중단).
