# 0.4.32 기술실 유료 연구 시작 상태

사용자 요구: 협동전 불곰 연구는 미리 완료되거나 효과가 지급되면 안 되며 기술실에서 광물·가스와 시간을 지불해야 한다.

0.4.31의 명령 허용은 연구 완료와 다르며, 그 패치가 해당 업그레이드를 직접 완료한 코드는 발견되지 않았다. 증상을 인정하되 원인을 확정하지 않는다. 이번 수정은 새 임무에서 세 협동전 연구가 미연구임을 명시적으로 보장한다. 기존 gf_m4_Init은 map initialization에서 1회 호출되므로 연구 중/후나 저장 로드 시 리셋하지 않는다. 자기가속 탄약의 기존 원작 LeaderAlias=MarineSuperStim은 자기 자신으로 분리한다. 이를 실제 자동 완료 원인이라고 확정하지 않는다.

대상: RM4_Suppression, MarauderMagrailMunitions, RM4_Shrapnel. 충격탄의 히페리온 구매 동기화는 기존 규칙대로 유지한다. 비용·시간·카드 배치·대상 유닛과 1~3번 임무는 보존한다.

검증: 전체 check_release 통과, 표시/선행/중복 방지 14개 사례 통과. 추가 정적 검사에서 각 0단계 초기화가 gf_m4_Init에 1회만 존재하며 세 업그레이드에 대한 스크립트 자동 AddLevel이 없음, 세 협동전 연구의 양수 광물·가스·시간과 CompleteOnly 효과 조건이 보존됨을 확인했다. ZIP CRC 및 XML 통과. 변경 파일은 metadata.txt, TTychus01의 mapscript.galaxy와 upgradedata.xml뿐이다. 에디터·Galaxy 컴파일·실제 게임은 미실행이다.

게임에서 새 어부지리 시작 후 기술실 연구 전/후 각각 실제 능력 발동과 연구 자원·시간 소모를 확인해야 한다. 게임 해결 여부는 미확인이다.
