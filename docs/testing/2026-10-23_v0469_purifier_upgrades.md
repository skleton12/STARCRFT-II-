# 0.4.69 — 정화자 공방업·보호막 방어력 누락 보정

사용자 보고: 정화자 일부 유닛은 공업만, 일부는 방업만 적용된다. 방업 시 보호막 방어력도 함께 올려 달라는 요청.

원인: 0.4.17의 연동 목록은 당시 이식된 유닛·무기 ID만 수집했다. 0.4.42 이후 추가된 유닛과 0.4.64의 사도 전용 무기에는 갱신되지 않았다. 기존 동기화는 지상 공방업만 부여해 공중 공격·장갑 업그레이드는 전달하지 않았고 보호막 업그레이드도 없었다.

어부지리의 gf_rmUpSync에서 레이너 보병 공업 단계에 정화자 지상·공중 공업을, 보병 방업 단계에 지상·공중 장갑과 보호막 업그레이드를 맞춘다. 기존 일반/울트라 커패시터/바나듐 단계 판정과 원시저그 연동은 보존한다. 각 단계가 없을 때만 1회 부여하므로 반복 틱·저장 후 재개 때 덧쌓지 않는다.

수정 대상: 파수병, 사도, 동력기, 선동자, 불멸자, 거신, 분열기 기본 무기, 보전기·전개 형태, 신기루, 정찰기, 폭풍함, 우주모함·요격기, 탐사정. 사도 분신의 공격 증가도 포함한다. 공격 주문·피닉스 영웅 능력이나 보류된 개별 연구는 새로 추가하지 않는다. 기본 지상·공중 무기 원본 증가량과 공업 레벨·아이콘, 방어력·방어력 레벨·아이콘, 보호막 방어력·단계·아이콘의 빠진 연결만 추가한다. 보호막 방어력은 단계당 +1이며 기본 보호막량은 변경하지 않는다. 표준 보호막 업그레이드에 이미 들어 있는 정화자 건물에도 같은 방업 단계가 전달된다.

SC2GameData 6dd323aae4209a01f110719a00b4e8f7a88389bc의 Core/Liberty/LibertyCampaign/LibertyStory 업그레이드 부모와 맵의 추가 레코드를 합쳐, 원래 적용되던 참조는 추가하지 않는다. 예: 불멸자·우주모함·요격기 기본 연결은 부모 업그레이드에서 이미 적용된다. 파수병과 동력기의 기존 LifeArmor +1도 중복 추가하지 않는다. 이후 유닛·무기를 추가할 때 검사 목록과 연동 목록을 같이 갱신해야 한다.
