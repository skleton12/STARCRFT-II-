## 파일 검사

ZIP CRC·경로 중복·XML 파싱을 이번 점검에서 통과했다. 앞선 빌드 검사에서는 원본 3번 지형/트리거/지역/의존성, 1번 전체, 2번 제한된 변경 범위, 에셋 보존과 새 플레이어 슬롯을 확인했다. Galaxy 컴파일·SC2 실행은 하지 못했다.

## Claude가 검토할 항목

1. 최신 정화자 규칙 미반영: 0.3.1은 파수병 8·선동자 2·동력기 1을 유지한다. 선동자 StalkerPurifier를 피닉스 협동전 병력으로 간주하면 안 된다. ZealotPurifier에도 피닉스 변환·카락스 재구축 연결이 혼재한다. 실제 사령관 생산 데이터에 맞춰 재편이 필요하다.
2. 건물 파괴 후 지원 재개 누락: mission03_support.galaxy의 Tick은 gv_m3_pylon·gv_m3_hatchery의 생존을 검사한다. AISetStock으로 같은 건물을 재건해도 이 두 핸들을 새 건물로 갱신하는 경로가 없다. 원래 건물이 죽으면 새 건물이 살아 있어도 해당 지원은 재개되지 않는 코드다. 초기 건설 중 사망 시에는 Arrive 함수도 즉시 종료한다.
3. 핑 만료 즉시 복귀 미보장: 30초 뒤 목표 변수는 기본 방어선으로 돌아가지만 Attack은 UnitOrderCount==0일 때만 명령한다. 기존 핑 명령이 계속 실행 중이면 30초가 지나도 즉시 기본 행동으로 전환하지 않는다. 실제 이동·교전 중 재현 검사가 필요하다.

이 점검에서는 구현·맵·ZIP을 수정하지 않았다. 위 기능 문제를 해결했다고 보고하지 않는다.
