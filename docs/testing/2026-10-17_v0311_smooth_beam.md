# 0.3.11 — 정화 광선 부드러운 이동 (2026-10-17)

사용자 보고: "광선이 너무 딱딱딱딱 움직임", "드래그 안 되는 경우 있는데 버그임?". 도구: `tools/build_v0311.py <0.3.10 zip> <출력>`.

## 광선
- 원인: 0.3.8~0.3.10은 0.25초마다 광선을 1칸씩 순간이동, 남은 적 추적도 적 위치로 바로 옮김.
- 수정: 광선 유닛(비행, 속도 4)에 이동 명령 → 엔진이 부드럽게 비행. 스크립트는 0.125초마다 위치를 읽고 0.25초마다 그 자리를 태움(0.3.8 피해 그대로). 경로: 5줄 왕복 꺾이는 점 10개. 남은 적 추적은 가장 가까운 적으로 이동 명령(0.5초마다 갱신), 최대 30초.
- 이동 명령이 안 먹어 멈춰 있을 때만 0.5칸씩 보간 이동으로 대신 민다(`gf_m3_BeamPush`).

## 드래그 선택
- 세 맵 스크립트에 화면을 가리는 대화창·선택 제한 코드 없음 (정적 확인). 재현 조건(맵·상황·선택하려던 유닛) 필요.
- 참고: 동맹(정화자·원시저그) 유닛은 다른 플레이어 소유라 드래그로 선택되지 않는 것이 게임 기본 동작.

## 미실행
