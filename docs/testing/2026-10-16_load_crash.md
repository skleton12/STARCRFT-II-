# 로딩 튕김 조사


## 2026-10-16: 로딩 튕김 조사·연결 누락 보정 — 0.2.23

사용자가 로딩 중 또는 시작 직후 튕김을 보고했다. 0.2.21은 실행해 보지 않았다고 답해 문제 발생 최초 버전은 미확정이다. 사용자 원본 0.2.16과 대조해 1번 미션 전체 및 2번 미션 지형·mapinfo·플레이어 설정·documentheader·regions·triggers 동일성을 확인했다. 지형 확장으로 돌아간 것이 아니다. 기존 저장 게임/새 미션 여부는 확인 요청 중이다.

데하카 바퀴 공격 ImpactMap이 참조하는 DehakaRoachMissileImpact 모델이 이식본에 없음을 확인해 추가했다. 미정의 추가 사망 음성 링크와 미이식 변이 능력의 잔여 소리 연결도 제거했다. 0.2.23은 확인된 데이터 결함의 보정본이며 튕김 원인을 확정하거나 게임 해결을 검증한 버전이 아니다. 직전 버전 대비 metadata·actor 2개·모델 1개만 바뀌며 유닛 능력치·소환 구성·타이밍·자원·지형·기존 스크립트는 유지한다. 파일명은 RaynorMercs_WoL_CCM.zip으로 고정한다.

검사: 입출력 ZIP CRC·XML 파싱, 누락 모델 참조의 해소, actor의 미정의 링크 제거, 직전 버전 대비 세 파일만 변경. Galaxy 컴파일·게임 실행·실제 로딩 성공은 미실행이다. 새 미션과 기존 저장 게임을 구분해서 재시험해야 한다.

재현: `python3 tools/patch_dehaka_links.py 입력_0.2.22.zip 새폴더/RaynorMercs_WoL_CCM.zip`.
