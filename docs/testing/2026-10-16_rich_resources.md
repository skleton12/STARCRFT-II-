# 0.2.19 — 아군 풍부한 자원·매장량 20% 증가 적용

사용자가 기존 자원 규칙의 누락을 지적해 0.2.18을 기준으로 적용했다.

## 변경 범위

- 2번 미션 레이너 본진 광물 10덩이(ID 2, 6, 20, 23, 24, 26, 27, 35, 308, 309)를 RichMineralField로 변경.
- 본진 가스 ID 28을 RichVespeneGeyser로 변경.
- 각 지점의 원래 Resources와 난이도별 Resources/Value를 각각 6/5배로 변경. 정수 미만은 버린다. 원래부터 존재하는 난이도별 AIActive 설정은 유지한다.
- 기본 매장량 합계: 광물 17673→21203, 가스 3254→3904. 어려움·아주 어려움 등 개별 override도 따로 증가시켰다.
- 적 본진 광물 8덩이, 중립 자원 상자, 기타 모든 배치·위치·ID는 그대로다.
- 1번 미션에는 해당 채취 자원이 없어 모든 파일을 그대로 보존했다. 지원군 진영에 새로운 자원이나 경제 구조를 만들지 않았다.
- 시작 보유 광물·가스, 채취 시간·속도에 별도 20% 보정을 하지 않았다. 풍부한 자원 고유의 채취량은 기본 게임 데이터를 따른다.
- 풍부한 정제소 RefineryRich를 기존 정제소 튜토리얼의 완성 조건에 함께 포함했다. 시작 광물 튜토리얼 선택도 RichMineralField를 가리키게 했다. 기존 기타 튜토리얼은 유지한다.

SC2Mapster/SC2GameData의 liberty 기본 UnitData에서 RichMineralField, RichVespeneGeyser, RefineryRich 정의와 Refinery의 BuiltOn/BuildOnAs 연결을 확인했다. TerranBuild의 Build8은 RefineryRich 건설에 연결되어 있고 캠페인 해당 카탈로그에는 이를 덮어쓰는 별도 정의가 없었다. 새로운 종속성이나 에셋을 추가하지 않았다.

재현: `python3 tools/patch_rich_resources.py 입력_0.2.18.zip 새_출력.zip`.

## 검사

ZIP CRC, XML 37개 파싱, 변경 엔트리가 metadata·2번 미션 objects·mapscript 세 개뿐임을 검사했다. 대상 자원 11곳의 기본·난이도별 수치 31개 증가, 비대상 배치 객체 동일성, 1번 미션 전체 동일성, 중복 패치 거부를 확인했다. 기존 4→3→1 소환과 정화자 수정탑 모델 연결은 유지한다. 업그레이드는 3번 미션용 계획으로만 남긴다.

미실행: Galaxy 컴파일, 게임/에디터 실행, 풍부한 가스 위 정제소 건설·채취와 난이도별 실제 표시값. 시험은 새 미션 시작으로 진행하며 기존 저장 게임의 자원이 자동 변환된다고 가정하지 않는다.
