# 0.4.31 불곰 연구 표시 수정 시험본

사용자가 확인한 재현은 0.4.30 / 어부지리 / 새 임무 시작이며, 충격탄이 첫째 줄에 보이지만 자기가속 탄약과 파편탄은 없다. 정적 정의 존재만으로 실제 연결이 정상이라고 판단했던 이전 답변을 정정한다.

## 변경

추가 연구는 원본과 별도인 RM3_TechResearch Research6~9이다. 기존 gf_m4_Mercs는 네 Upgrade를 허용하지만 네 AbilCmd를 허용하지 않는다. 초기화와 2초 주기에서 이 함수가 재적용되므로 여기에 명령 허용을 추가했다. 원본 충격탄은 XML에서 Suppressed이지만 사용자 화면에는 보인다. 따라서 원본 명령도 런타임에서 별도로 금지한다. 해금 마커는 생산 명령 허용 또는 실제 망치 경호대 소유 시 한 번 활성화한다. 앞서 소유에만 의존하던 문제가 재발하지 않도록 생산 명령 허용 경로도 유지한다.

명령 허용과 연구 요구조건은 별개다. 미해금 때는 세 연구가 숨겨지고, 해금 후 미연구 때는 충격탄·자기가속·파편탄이 보이는 기존 요구조건을 유지한다. 충격탄 완료 후 같은 자리의 억제탄으로 진행하고, 연구 대기·완료 항목은 숨긴다. 기존 연구 대상은 망치 경호대이며 이지스 근위대까지 확대하지 않는다.

## 검증

- 원본 0.4.30과 ZIP 파일 목록/순서 일치, 중복 경로 없음. 변경은 metadata.txt와 TTychus01.SC2Map/mapscript.galaxy뿐이다. 다른 파일 바이트 보존.
- python3 tools/check_release.py releases/RaynorMercs_WoL_CCM.zip: 네 임무 전체 통과. 원작 XML 참조는 SC2Mapster/SC2GameData에서 보완했다.
- python3 tools/check_marauder_research.py releases/RaynorMercs_WoL_CCM.zip: 14개 해금/선행/중복 연구 사례 통과, 전체 XML 파싱 및 CRC 통과. 이 검사는 실제 게임이 아닌 XML 요구조건 평가다.
- 기존 초기화와 주기 함수가 수정한 gf_m4_Mercs를 호출하는 것 확인.
- Galaxy 컴파일·에디터·실제 SC2 실행은 불가하여 미실행. 실제 버튼 표시 문제 해결은 확인 전이다.

## 게임 확인 항목

새 어부지리에서 불곰 해금 후 병영 기술실을 선택한다. 둘째 가로줄의 충격탄(또는 이미 구매했다면 억제탄), 자기가속 탄약, 파편탄을 확인한다. 원본 첫째 줄 충격탄은 사라져야 한다. 각각 연구한 뒤 중복 연구가 막히고, 망치 경호대에 기존 효과가 적용되는지 확인한다. 여전히 동일하다면 명령/요구조건 실제 런타임 값과 로드된 맵 카탈로그를 관찰해야 하며 추가 원인을 단정하지 않는다.
