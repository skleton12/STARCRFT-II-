# 0.2.18 — 정화자 첫 지원군 4→3→1 묶음 소환

사용자 요청으로 0.2.17 시험본에 적용했다. 통합 CCM은 `RaynorMercs_WoL_CCM_v0.2.18.zip`이며 1·2번 미션을 포함한다.

- 최초: 파수병 4기 → 파수병 3기 → 선동자 1기, 총 8기. 이전 최초 구성(파수병 6기·선동자 1기)보다 파수병 1기가 늘었다.
- 각 묶음의 워프 효과를 동시에 시작하고 1게임초 후 해당 묶음을 대기 없이 생성한다. 이후 1게임초를 두고 다음 묶음의 효과를 시작한다. 시작 기준 1초·3초·5초에 생성된다. 엔진 프레임 오차는 별도다.
- 반복 지원은 파수병 2기 → 선동자 1기, 총 3기를 유지한다. 첫 2기도 같은 틱에 생성한다.
- 20기 상한의 남은 자리만 생성한다. 효과 시작 전과 생성 직전에 병력 수를 확인한다. 대기 중 수정탑 파괴 또는 게임 종료 시 생성하지 않고 워프 효과를 정리한다.
- 생성 위치는 수정탑 남쪽에 분산 배치한다. 해당 위치 주변 3×3 칸이 1단계 지형임을 검사했다. 장식물·유닛 footprint 충돌을 검증한 것은 아니다.
- 기존 건설 16초·완공 후 5초, 집결 후 출발, 재소환 간격, 원시 저그, 수정탑 모델 연결, 코랄의 후예 및 3번 미션용 미구현 연구 계획은 유지한다.

재현: `python3 tools/patch_grouped_warp.py 입력_0.2.17.zip 새_출력.zip`.

검사: 입출력 CRC, 전체 XML 37개 파싱, metadata와 2번 미션 mapscript 두 파일만 변경, 함수 전후 스크립트 동일성, 생성 루프 내 대기 없음, 0~20기 경계값 21건의 병력 상한 계산 모델, 중복 패치 거부, LF/CRLF 유지. 상한 계산은 정적 코드와 별도 수치 모델 검사이며 Galaxy 실행 결과가 아니다.

미검증: Galaxy 컴파일, 실제 SC2 소환 시각·모델·충돌·집결. 정화자 수정탑 리소스 표시도 이전 시험본과 동일하게 미확인이다.
