# 0.4.36 — 원인 관찰 전용, 표시 문제 해결본 아님

사용자는 0.4.35에서도 일반 병영 기술실에 추가 연구가 표시되지 않는다고 재확인했다. 기술 반응로 가설로 현재 증상을 설명하지 않는다. 정적 파일 검사의 연구 정의·배치·조건만으로 실제 로드 상태를 알 수 없다. 앞선 수정본을 실제 해결로 간주하지 않는다.

기술실(일반/병영/기술 반응로)을 선택하면 선택된 유닛의 실제 ID, RM3_TechResearch 능력 존재/활성 여부, 불곰 해금 마커와 생산 허용, 세 연구의 실제 완료 단계, 각 연구 명령의 허용, 게임 카탈로그가 반환한 연구 버튼 연결/좌표를 채팅 영역에 출력한다. 버전 0.4.36 표식으로 실제 스크립트 로드도 구분한다. 연구 상태나 데이터/요구조건을 변경하지 않는다. 진단이 전혀 안 나오면 스크립트 실행/로드 자체부터 확인한다.

0.4.35와 비교해 metadata, 어부지리 스크립트, 12언어 진단 문자열만 변경. 전체 check_release 통과, 연구 조건 15사례 통과, 새 콜백 네이티브 호출 57개 인수 개수 대조 통과. 실제 Galaxy 컴파일·SC2 실행은 미실행.

별도 codex/techlab-diagnostic-0436 브랜치의 시험본이며 Claude 구현 브랜치의 정식 파일을 교체하지 않는다. 사용자가 새 어부지리에서 병영 기술실을 선택하고 출력된 진단 내용과 연구창을 보내 주면 그 값에 근거해 후속 수정한다.
