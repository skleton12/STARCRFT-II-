# 0.2.21 — 지속 지원 통합·동력기·파수병 재구축

## 사용자 지시 반영

- 최초·후속 병력 구분을 없애고 같은 구성을 계속 반복한다.
- 정화자는 매 차수 파수병 8, 선동자 2, 동력기 1을 요청한다. 묶음은 4+4+2+1이며, 기존 생존 20기 제한 때문에 남은 자리가 부족하면 일부만 소환된다.
- 원시 저그는 매 투하 저글링 6, 협동전 라바사우르스 2, 원시 히드라 2, 원시 바퀴 2를 요청한다. 최초·후속 구성의 합집합이며, 90초 반복한다. 기존 생존 인구수 20 이상이면 보류하는 조건을 유지한다. 한 차수는 현재 데이터 기준 인구수 15이므로 20을 넘는 투하가 가능하다. 이는 상한을 20으로 자르는 규칙과 다르다.
- 정화자 반복 간격은 집결·출발 처리 후 90초, 원시 저그는 투하 후 90초다. 조건 확인은 기존 2초 주기다. 증원 횟수 제한은 없다.
- 파수기 종류는 사용자가 동력기(공격·이동 속도 지원)를 선택했다. 용병은 기존 고용소 유료 고용 방식을 유지하며 이번에 무료 자동 증원을 추가하지 않았다.

## 동력기

SC2Mapster/SC2GameData의 공허 캠페인·협동전 동력기를 바탕으로 지원에 필요한 부분을 `RM21_` ID로 분리했다. 유닛, 공격·지원 광선, 모델·연출·소리·버튼·검증자·정렬을 포함한 48개 항목을 추가했다. 시간 광선은 자동 시전이며 공격 속도 +25%, 이동 속도 +50%, 지속 10초다. 기본 에너지 비용·회복을 따른다. 이번 지원용 동력기에는 위상 전환·정신 지배·사령관 성장 체계를 넣지 않았다. 외부 M3/텍스처는 설치 게임 리소스를 사용하며 실제 표시·시전은 미검증이다.

## 파수병 재구축 누락 원인과 수정

기존 이식 데이터에서 ZealotPurifier의 BehaviorArray index 0이 빈 링크로 덮였고, ZealotResearchReconstruction 해금이 없었다. 부활 재사용 대기 행동의 InitialEffect/ExpireEffect도 빈 값으로 다시 덮여 있었다. 8번 진영에서 부활 행동과 연구 해금을 복원하고, 재사용 대기 시작에 부활 행동을 제거하고 120초 후 다시 부여하는 연결을 복원했다. 카락스 전용 잠금 버튼·프리로드 조건을 제거했다. 치명상 → 잔해 변환 → 약 6.7초 재구축 → 회복 → 120초 재사용 대기의 원래 연결을 사용한다. 새 무한 부활·무적 규칙을 만들지 않았다.

## 보존·검사

원본 136×136 지형, 1번 미션 전체, 모든 배치 객체, 풍부한 자원 및 매장량 20% 증가, 주민 중립 설정, 협동전 드롭포드, 정화자 수정탑 연결을 보존했다. 연구는 여전히 3번 미션용 계획이다.

입출력 ZIP CRC, XML 및 ID 중복 검사, 새 항목 부모·RM21 내부 참조, 자동 시전·버프 수치, 부활 해금·냉각 연결, 정화자 병력 경계값 21건의 계산 모델을 검사했다. 반복 구성은 코드 검사이며 실제 게임 시뮬레이션이 아니다. Galaxy 컴파일·SC2 실행·부활·버프·연출·충돌은 미실행이다. 새 미션 시작으로 시험한다.
