# Claude 인수인계 — 정화자·협동전 원시저그 조사

2026-10-20 / 사용자 요청: 정화자(협동전·공허 캠페인)와 데하카 협동전 원시저그 자료를 조사해 구현을 돕는다. **문서 전달이며 맵 구현·새 편성 승인이 아니다.** 최신 `46d3ac6` 기록의 피닉스 영웅 전투복 제외를 반영했다.

먼저 [정화자·원시저그 참고서](research/purifier_and_primal_unit_reference.md)를 읽는다. [기계 판독용 색인](research/data/ally_unit_reference_index.json)에는 63개 그룹별 유닛 항목과 연구 정의 후보 53개가 있다. 후보 전체를 현재 플레이 가능한 연구로 간주하지 않는다.

## 구현 전에 확인할 핵심

- `FenixDragoon`, `FenixArbiter`는 영웅 전투복이며 최신 기록에서 이미 제외됐다. 일반 용기병/중재자로 다시 넣지 않는다.
- **피닉스(Fenix)**와 비행 유닛 계열 **불사조(Phoenix)**는 다르다. `PhoenixPurifier`의 정식 유닛은 **신기루(Mirage)**다.
- 피닉스 일반 전투 병력: 군단병, 사도, 보전기, 불멸자, 거신, 분열기, 정찰기, 우주모함. 관측선/탐사정은 지원. 여섯 용사와 영웅 전투복은 별도.
- 카락스 일반 전투 병력: 파수병, 동력기, 불멸자, 거신, 신기루, 우주모함. 보전기/동력기, 군단병/파수병을 같은 능력의 유닛으로 취급하지 않는다.
- 선동자와 폭풍함은 공허 캠페인 정화자 자료에 포함하지만 피닉스·카락스 일반 생산 유닛이 아니다. 기존 협동전 한정 규칙을 조사만으로 바꾸지 않는다.
- `DehakaSwarmHost` = **원시 숙주**, `DehakaPrimalSwarmHost` = **땅무지 숙주**. 기존 해금표의 원시 숙주 ID 설명을 바로잡아 읽는다.
- **관통촉수 `ImpalerDehaka`가 실제 존재**한다. 원시 가시지옥을 별도 제외한 것과 관통촉수 존재를 혼동하지 않는다.
- 원시 감시자의 알 최종 결과는 저글링 `DehakaZerglingLevel2`, 바퀴 `DehakaRoachLevel2`, 히드라 `DehakaHydraliskLevel2`, 숙주 `DehakaSwarmHost`, 울트라 `DehakaUltraliskLevel2`다. 이름이 짧다는 이유로 다른 버전을 고르지 않는다.
- 원시 뮤탈 최종형은 `DehakaMutaliskLevel3`. `FightMorph` 개체는 변태 과정이지 영구 최종형이 아니다.
- `Immortal`/`Scout`/`Carrier`는 공용 Unit ID다. 액터/모델/스킨과 사령관 Upgrade를 별도로 확인한다. `ScoutFenix`는 확인한 **모델** ID이며 일반 유닛 ID는 `Scout`다.

## 검증 범위

원작 데이터 공개 미러의 고정 커밋을 출처로 삼고, 협동전 유닛·능력·업그레이드 및 공허 캠페인 유닛·능력 5개 카탈로그가 조사 파일과 같은 바이트인지 확인했다. 본문에 적은 개별 카탈로그 ID/타입은 원본 정의에 존재함을 확인했다. 생산 알→최종 유닛, 원시 전투→결과, 세 무리 우두머리 연구 건물의 실제 명령창 연결을 대조했다.

실제 에디터·SC2 실행은 하지 않았다. 단일 XML 수치, ID 존재, 모델 존재만으로 최종 협동전 능력치·생산 가능 여부·게임 동작을 검증했다고 하지 않는다. 상세 연결/출처/이식 점검 순서는 참고서를 따른다.
