0.6.26 동맹 구성 수정
- 이전 버전은 3/5/6번 지원 버튼에 근접병 +1, 저글링 +2만 추가했고 4번 자동 생산은 그대로였음.
- 3/5/6번 기본 지원을 정화자 군단병 6·사도 3·조건부 동력기 1 / 원시저그 저글링 10·바퀴 2·히드라 3으로 증원. 연구실 단계·해금 보너스 별도.
- 유료 기본 구성 경계는 유지하고 추가분은 무료. 자동 지원 경로도 무료 경계를 따르게 수정.
- 호출 후 실제 그룹 수를 화면에 표시. 동력기 보유량과 단계에 따라 총수는 달라짐.
- 지원 배열 용량을 32로 확대. 최대 연구실/해금 조합 23기를 수용.
- 3~6번 동맹 군대 인구 상한 100→120.
- 4번은 기존 자동 생산 외에 4분부터 120초마다 정화자 근접병 2·사도 1 / 저글링 2·히드라 1 무료 보충. 인구 상한 준수.
- 1~6번 정화자 파수병을 피닉스 군단병 모델과 전투 설정으로 전환. 체력 200/보호막 100/기본 공격 16×2/인구 3. 기존 호출 비용을 유지하기 위해 유닛 비용은 기존 값 유지.
- 파수병 재구축 동작과 아이콘 제거, 군단병 모델·사망·소환·아이콘 리소스 포함. 기존 돌진과 동맹 조종 방식 유지.
- 적 유닛 무기에 영향이 없도록 군단병 전용 무기/피해 효과 사용. 해당 무기도 지상 공업 적용.
- 이전 피닉스/칼달리스/초상화/키/적 밸런스 수정 포함. 적 AI 난이도 및 적 강화 설정은 변경하지 않음.
검증: XML 구문, 군단병 능력치/무기 연결, 증원 배열 용량, 기존 적 AI/보정 함수 및 영웅 소환 코드 동일 비교, ZIP 무결성 통과.
게임 플레이테스트는 미실시. 새 임무에서 소환 후 표시되는 수와 군단병 외형을 확인해야 함. 기존 저장에는 이전 편성이 남을 수 있음.
