# Raynor Mercenaries 동맹 3단계 업그레이드 설계

기준 버전은 0.6.26이다. 이 문서는 대화에서 정한 설계를 저장한 것이며, 건물과 연구 시스템은 아직 맵에 구현되지 않았다.

## 적용 범위

| 건물 | 적용 임무 | 연구 대상 |
| --- | --- | --- |
| 데하카 굴 | 3번 맵부터 | 원시저그 동맹 |
| 정화자 대의회 | 3번 맵부터 | 정화자 동맹 |

각 건물의 연구는 1단계, 2단계, 3단계로 구성한다. 각 단계는 해당 진영 유닛의 전용 기술 묶음을 해금한다. 공방업은 기존 체계에서 별도로 관리한다.

## 단계 구성

| 진영 | 단계 | 유닛 | 기술 | 상태 |
| --- | --- | --- | --- | --- |
| 원시저그 | 1단계 | 원시 저글링 | 대사 촉진, 아드레날린 분비선 | 사용자 제시 예시 |
| 원시저그 | 2·3단계 | 미정 | 미정 | 편성 결정 필요 |
| 정화자 | 1·2·3단계 | 미정 | 미정 | 편성 결정 필요 |

상위 단계에서도 앞 단계 효과를 유지한다. 연구 완료 시 현재 동맹 병력과 이후 소환되는 병력에 동일한 효과를 적용한다. 유닛을 선택하면 적용된 기술의 아이콘과 설명을 표시한다.

## 구현과 확인 항목

1. 두 건물의 배치, 소유자, 연구 조작 주체를 정한다.
2. 단계마다 대상 유닛, 효과, 아이콘, 비용과 연구 시간을 정리한다.
3. 일반 저그·프로토스 기술의 효과를 맵에서 실제 사용되는 원시저그·정화자 유닛에 연결한다.
4. 연구 완료 상태를 효과와 아이콘 표시의 공통 기준으로 삼아 중복 적용을 막는다.
5. 단계별 연구 전후, 기존 병력과 신규 소환 병력, 아이콘과 실제 효과 일치를 게임에서 확인한다.
